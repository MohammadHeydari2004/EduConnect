# سامانه مدیریت آموزشی EduConnect (EduConnect LMS)

## 📖 معرفی پروژه

پروژه **EduConnect** یک اپلیکیشن تحت وب پیشرفته و واکنش‌گرا (Responsive) است که جهت مدیریت یکپارچه فرآیندهای آموزشی، شامل مدیریت کاربران، کلاس‌ها، جلسات، حضور و غیاب و اطلاعیه‌ها طراحی و توسعه یافته است.
این مخزن (Repository) به‌طور اختصاصی شامل **کدهای سمت کلاینت (Front-End)** بوده و برای شبیه‌سازی عملکرد سرور (Back-End) و پایگاه داده، از ابزار `json-server` به عنوان یک Mock API استفاده می‌کند.

---

## ✨ ویژگی‌های کلیدی و امکانات پیاده‌سازی‌شده

### 🔐 مدیریت احراز هویت و امنیت (Authentication & Authorization)

- سیستم ورود (Login) با اعتبارسنجی اطلاعات و مدیریت Sessionها.
- ذخیره‌سازی امن وضعیت احراز هویت در `LocalStorage`.
- محافظت از مسیرها (Protected Routes) جهت جلوگیری از دسترسی کاربران غیرمجاز.
- **کنترل دسترسی مبتنی بر نقش (RBAC):** تفکیک کامل دسترسی‌ها برای سه نقش اصلی:
  - **مدیر (Admin):** دسترسی کامل به تمامی بخش‌ها و مدیریت کاربران.
  - **استاد (Teacher):** مدیریت کلاس‌های اختصاصی، ثبت حضور و غیاب و ارسال اطلاعیه.
  - **دانشجو (Student):** مشاهده کلاس‌ها، وضعیت حضور و غیاب و اطلاعیه‌ها.

### 👥 مدیریت کاربران (Users Management)

- عملیات کامل CRUD (ایجاد، خواندن، به‌روزرسانی و حذف) اختصاصی برای مدیر سیستم.
- اعتبارسنجی فرم‌ها و جلوگیری از تداخل ایمیل‌ها.
- منطق تجاری (Business Logic) جهت جلوگیری از حذف یا غیرفعال‌سازی آخرین مدیر سیستم.

### 🏫 مدیریت کلاس‌ها و جلسات (Classes & Sessions)

- ایجاد کلاس‌ها با تعیین ظرفیت، استاد راهنما و لیست دانشجویان.
- تعریف جلسات متعدد برای هر کلاس به همراه تاریخ و توضیحات اختصاصی.
- تغییر وضعیت کلاس‌ها (فعال / غیرفعال).

### 📊 سیستم حضور و غیاب (Attendance Tracking)

- ثبت وضعیت حضور دانشجویان (حاضر، غایب، با تأخیر) توسط اساتید برای هر جلسه.
- محاسبه خودکار آمار حضور (درصد حضور، تعداد غیبت‌ها) و نمایش گرافیکی آن.
- نمایش جزئیات جلسات و وضعیت حضور در پروفایل اختصاصی دانشجویان.

### 📢 سیستم اطلاعیه‌ها (Announcements)

- ارسال اطلاعیه‌های عمومی (برای همه کاربران) یا اختصاصی (برای یک کلاس خاص).
- هدف‌گیری دقیق مخاطبان بر اساس نقش‌ها یا اعضای یک کلاس.
- سیستم پیگیری خوانده‌شدن اطلاعیه‌ها (Seen/Unseen Tracking) برای هر کاربر.

### 🎨 رابط کاربری و تجربه کاربری (UI/UX)

- طراحی کاملاً **واکنش‌گرا (Responsive)** و سازگار با موبایل، تبلت و دسکتاپ با استفاده از **Tailwind CSS**.
- استفاده از معماری کامپوننت‌محور و المان‌های UI قابل استفاده مجدد (Reusable).
- مدیریت وضعیت‌های بارگذاری (Loading States) و حالت‌های خالی (Empty States).
- نمایش پیام‌های موفقیت و خطا (Toast/Alerts) پس از انجام عملیات.

## 🚀 راهنمای نصب و راه‌اندازی

جهت راه‌اندازی پروژه، مراحل زیر را به‌ترتیب در ترمینال سیستم خود دنبال نمایید:

### ۱. نصب وابستگی‌ها (Dependencies)

ابتدا وارد دایرکتوری اصلی پروژه شوید و دستور زیر را جهت نصب تمامی پکیج‌های موردنیاز اجرا کنید:

```bash
npm install
```

### ۲. راه‌اندازی سرور شبیه‌ساز (Mock API)

این پروژه جهت ذخیره‌سازی داده‌ها از یک فایل محلی به نام `db.json` استفاده می‌کند. برای اجرای این سرور مجازی بر روی پورت `3001`، دستور زیر را اجرا نمایید:

```bash
npm run server
```

> **توجه مهم:** این ترمینال باید در طول زمان استفاده از اپلیکیشن باز و در حال اجرا باقی بماند.

### ۳. اجرای اپلیکیشن فرانت‌اند

در یک ترمینال جدید (بدون بستن ترمینال سرور)، دستور زیر را جهت راه‌اندازی سرور توسعه Vite وارد کنید:

```bash
npm run dev
```

پس از اجرای موفقیت‌آمیز، اپلیکیشن به‌صورت پیش‌فرض بر روی آدرس `http://localhost:5173` (یا پورت پیشنهادی ترمینال) در دسترس خواهد بود.

## 📜 اسکریپت‌های موجود (NPM Scripts)

در فایل `package.json` اسکریپت‌های زیر جهت تسهیل فرآیند توسعه تعریف شده‌اند:

| دستور             | توضیحات                                                          |
| :---------------- | :--------------------------------------------------------------- |
| `npm run dev`     | راه‌اندازی سرور توسعه (Development Server) با قابلیت Hot Reload. |
| `npm run build`   | ایجاد نسخه نهایی، بهینه‌سازی‌شده و فشرده (Production Build).     |
| `npm run preview` | پیش‌نمایش نسخه Production ساخته‌شده در محیط محلی.                |
| `npm run lint`    | بررسی کیفیت کد و رعایت استانداردها توسط ESLint.                  |
| `npm run server`  | اجرای `json-server` برای شبیه‌سازی API بر روی پورت 3001.         |

## 📂 ساختار دایرکتوری‌های پروژه (Project Structure)

```text
src/
├── components/       # کامپوننت‌های مشترک (Common) و المان‌های پایه UI
├── context/          # مدیریت سراسری State (مانند Context احراز هویت)
├── layouts/          # ساختارهای کلی صفحات (مانند MainLayout شامل هدر و سایدبار)
├── pages/            # صفحات اصلی اپلیکیشن (تفکیک‌شده بر اساس ماژول‌ها)
│   ├── auth/         # صفحات مرتبط با ورود
│   ├── dashboard/    # داشبورد اصلی
│   ├── users/        # ماژول مدیریت کاربران
│   ├── classes/      # ماژول مدیریت کلاس‌ها و جلسات
│   ├── attendance/   # ماژول حضور و غیاب
│   ├── announcements/# ماژول اطلاعیه‌ها
│   └── profile/      # پروفایل کاربری
├── routes/           # تنظیمات مسیریابی و گاردهای دسترسی (Role Guards)
├── services/         # لایه ارتباط با API و سرویس‌های تجاری (API Layer)
├── types/            # تعاریف، اینترفیس‌ها و Typeهای TypeScript
└── utils/            # توابع کمکی (مانند فرمت تاریخ) و ثابت‌های سراسری
```
