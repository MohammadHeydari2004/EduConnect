# 🎓 EduConnect

## سامانه جامع مدیریت آموزش و کلاس‌های آنلاین

**EduConnect** یک اپلیکیشن تحت وب تک‌صفحه‌ای (SPA) و کاملاً **واکنش‌گرا (Responsive)** است که با هدف مدیریت یکپارچه کلاس‌ها، دانشجویان، اساتید، تکالیف، اطلاعیه‌ها و حضور و غیاب طراحی و پیاده‌سازی شده است. این پروژه به‌عنوان یک راهکار فرانت‌اند مدرن، از پشته‌ی تکنولوژی روز شامل **React 19**، **TypeScript 6**، **Vite 8** و **Tailwind CSS** بهره می‌برد و با استفاده از **Context API** و **React Router**، معماری مقیاس‌پذیری را برای مدیریت احراز هویت و مسیریابی مبتنی بر نقش (Role-Based Access Control) ارائه می‌دهد.

## ✨ ویژگی‌های کلیدی

### 🔐 احراز هویت و مدیریت نشست

- صفحه ورود امن با اعتبارسنجی ایمیل و رمز عبور
- مدیریت نشست کاربر از طریق `localStorage`
- **Protected Routes** برای محافظت از مسیرهای خصوصی
- **Role Guards** برای محدودسازی دسترسی بر اساس نقش کاربر

### 👥 مدیریت کاربران (پنل مدیر)

- مشاهده، ایجاد، ویرایش و حذف کاربران
- فیلتر و جستجوی پیشرفته بر اساس نام، ایمیل، نقش و وضعیت
- اعتبارسنجی یکتا بودن ایمیل
- جلوگیری از حذف یا غیرفعال‌سازی آخرین مدیر سیستم

### 🏫 مدیریت کلاس‌ها

- ایجاد کلاس‌ها با ظرفیت مشخص و انتساب استاد و دانشجویان
- فعال/غیرفعال کردن کلاس‌ها
- نمایش جزئیات کلاس شامل لیست دانشجویان و جلسات
- دسترسی مدیریت برای مدیر و استادِ همان کلاس

### 📅 مدیریت جلسات

- تعریف جلسات مجزا برای هر کلاس با تاریخ و توضیحات
- ارتباط مستقیم با سیستم حضور و غیاب

### ✅ حضور و غیاب

- ثبت وضعیت دانشجویان (حاضر / غایب / با تأخیر) برای هر جلسه
- محاسبه آمار حضور (تعداد جلسات، درصد حضور، نوار پیشرفت)
- پنل اختصاصی برای دانشجویان جهت مشاهده سابقه حضور خود

### 📢 اطلاعیه‌ها

- ایجاد اطلاعیه‌های عمومی یا مخصوص یک کلاس خاص
- تعیین مخاطبان هدف (دانشجو، استاد، مدیر)
- سیستم نمایش وضعیت «خوانده شده / خوانده نشده»
- ویرایش و حذف اطلاعیه توسط نویسنده

### 📝 سیستم تکالیف

- تعریف تکلیف توسط استاد برای کلاس‌های تحت تدریس
- ارسال پاسخ توسط دانشجویان (متن، لینک یا GitHub)
- نمره‌دهی (از ۲۰) و ارائه بازخورد توسط استاد
- محاسبه میانگین نمرات برای هر تکلیف
- حذف خودکار پاسخ‌ها هنگام ویرایش یا حذف تکلیف

### 👤 پروفایل کاربری

- نمایش اطلاعات شخصی کاربر
- مشاهده آمار کامل حضور و غیاب (مخصوص دانشجویان)
- جدول تاریخچه جلسات شرکت‌شده

### 🎨 رابط کاربری

- طراحی کاملاً راست‌چین (RTL) با پشتیبانی از فونت **وزیرمتن**
- استفاده از **Tailwind CSS** برای استایل‌دهی مدرن و Utility-First
- کامپوننت‌های UI قابل استفاده مجدد (Button, Modal, Table, Card, Badge, ...)
- واکنش‌گرا برای نمایش بهینه در موبایل، تبلت و دسکتاپ

## 🚀 راهنمای نصب و راه‌اندازی

### گام اول: دریافت سورس پروژه

در صورتی که پروژه در یک مخزن Git میزبانی می‌شود، آن را کلون کنید:

```bash
git clone <repository-url>
cd educonnect
```

در غیر این صورت، فایل‌های پروژه را در پوشه‌ای دلخواه استخراج نمایید.

### گام دوم: نصب وابستگی‌ها (Dependencies)

در ریشه پروژه، دستور زیر را جهت نصب تمامی پکیج‌های موردنیاز اجرا کنید:

```bash
npm install
```

> ⚠️ **نکته مهم:** اجرای موفقیت‌آمیز این دستور، پوشه `node_modules` را ایجاد و فایل `package-lock.json` را به‌روزرسانی می‌کند. در صورت مواجهه با خطا، از به‌روز بودن نسخه Node.js خود اطمینان حاصل کنید.

### گام سوم: راه‌اندازی سرور شبیه‌ساز API (JSON Server)

این پروژه جهت شبیه‌سازی یک API واقعی RESTful، از **JSON Server** استفاده می‌کند. داده‌های پروژه در فایل `db.json` ذخیره می‌شوند.

برای اجرای سرور در **ترمینال اول**، دستور زیر را اجرا نمایید:

```bash
npm run server
```

پس از اجرای موفق، سرور JSON Server بر روی آدرس `http://localhost:3001` فعال خواهد شد و از طریق مسیرهایی نظیر `/users`، `/classes`، `/assignments` و غیره قابل دسترسی است.

### گام چهارم: راه‌اندازی سرور توسعه (Development Server)

در **ترمینال دوم** (باید به‌طور همزمان با ترمینال قبلی اجرا باشد)، دستور زیر را جهت راه‌اندازی اپلیکیشن React اجرا کنید:

```bash
npm run dev
```

پس از چند ثانیه، اپلیکیشن در حالت توسعه اجرا شده و در مرورگر از طریق آدرس زیر قابل دسترسی است:

```
http://localhost:5173
```

> 💡 **توجه:** هر دو ترمینال باید در طول استفاده از پروژه باز بمانند؛ ترمینال اول سرویس‌دهنده داده‌ها و ترمینال دوم رابط کاربری را ارائه می‌دهد.

## 🏛️ معماری و الگوهای به‌کاررفته

### ۱. معماری مبتنی بر ماژول (Modular Architecture)

پروژه به‌صورت ماژولار سازماندهی شده و هر قابلیت (مانند کاربران، کلاس‌ها، تکالیف) در پوشه‌ای مستقل درون `src/pages/` قرار دارد. این رویکرد نگهداری و مقیاس‌پذیری کد را تسهیل می‌کند.

### ۲. الگوی Service Layer

تمام درخواست‌های HTTP در پوشه `src/services/modules/` متمرکز شده‌اند. هر ماژول یک سرویس اختصاصی دارد (مانند `userService`, `classService`) که بر پایه یک `baseApi` عمومی بنا شده است.

### ۳. مدیریت State با Context API

وضعیت احراز هویت از طریق `AuthContext` و `AuthProvider` مدیریت می‌شود و در کل درخت کامپوننت‌ها از طریق Hook اختصاصی `useAuth` قابل دسترسی است.

### ۴. محافظت از مسیرها (Route Guards)

- **`ProtectedRoute`**: تضمین می‌کند تنها کاربران وارد شده بتوانند به صفحات خصوصی دسترسی داشته باشند.
- **`RoleGuard`**: دسترسی به هر صفحه را بر اساس نقش کاربر محدود می‌کند.

### ۵. TypeScript Strict Mode

پروژه با تنظیمات سخت‌گیرانه TypeScript پیکربندی شده تا از ایمنی نوع (Type Safety) در سراسر کد اطمینان حاصل شود. تعاریف نوع در پوشه `src/types/` به‌صورت متمرکز نگهداری می‌شوند.

## 🛡️ نقش‌ها و سطح دسترسی‌ها

پروژه از سه نقش اصلی پشتیبانی می‌کند:

### 👑 مدیر (Admin)

- دسترسی کامل به تمامی بخش‌های پروژه
- مدیریت کاربران و نقش‌ها
- ایجاد اطلاعیه‌های عمومی و تنظیم مخاطبان
- مشاهده تمامی کلاس‌ها و تکالیف

### 👨‍🏫 استاد (Teacher)

- ایجاد و مدیریت کلاس‌های تحت تدریس خود
- ایجاد و ویرایش جلسات برای کلاس‌هایش
- ثبت حضور و غیاب دانشجویان
- تعریف تکلیف و نمره‌دهی به پاسخ‌های دانشجویان
- ایجاد اطلاعیه برای کلاس‌های خود

### 👨‍🎓 دانشجو (Student)

- مشاهده کلاس‌های ثبت‌نام شده
- مشاهده تکالیف و ارسال پاسخ
- ویرایش پاسخ (پیش از نمره‌دهی)
- مشاهده آمار حضور و غیاب شخصی
- مشاهده اطلاعیه‌ها

## 📝 یادداشت‌های پایانی

- این پروژه صرفاً **فرانت‌اند** است و برای تأمین داده‌ها از JSON Server استفاده می‌کند. در محیط Production، می‌توان `baseURL` را در فایل `src/services/api/axiosInstance.ts` به آدرس API واقعی تغییر داد.
