## 📖 معرفی و چشم‌انداز پروژه

**EduConnect**
یک پلتفرم یکپارچه، تحت وب و مبتنی بر نقش (Role-Based) برای مدیریت فرآیندهای آموزشی، ارتباطی و نظارتی میان **دانشجویان، اساتید و مدیران گروه** است.
این سامانه با هدف شبیه‌سازی یک محیط واقعی دانشگاهی (LMS) طراحی شده و معماری آن بر پایه تفکیک دقیق دغدغه‌ها (Separation of Concerns) و توسعه مبتنی بر وابستگی (Dependency-Driven Development) استوار است.
هدف غایی این پروژه، ارائه یک راهکار نرم‌افزاری چابک برای پوشش نیازهای آموزشی، مدیریت کلاس‌ها، رصد حضور و غیاب، چرخه حیات تکالیف و ارائه داشبوردهای تحلیلی اختصاصی است.

## ✨ ویژگی‌های کلیدی و ماژول‌های پیاده‌سازی شده

### 🛡 مدیریت هویت و دسترسی‌ها (IAM & RBAC)

- **احراز هویت امن:** شبیه‌سازی ورود و خروج با استفاده از Context API و LocalStorage.
- **کنترل دسترسی مبتنی بر نقش:** محافظت از مسیرها (Protected Routes) و کامپوننت‌ها (Role Guards) برای سه نقش کلیدی: `Admin` (مدیر گروه)، `Teacher` (استاد) و `Student` (دانشجو).
- **مدیریت چرخه حیات کاربران:** ایجاد، ویرایش، تعلیق (Suspend) و تغییر نقش کاربران توسط مدیر سیستم.
- **محافظت از آخرین مدیر:** جلوگیری از حذف یا غیرفعال‌سازی آخرین کاربر با نقش `admin`.

### 🏛 مدیریت آموزشی (Academic Management)

- **مدیریت کلاس‌ها و جلسات:** تعریف دوره‌ها، تخصیص ظرفیت، انتصاب استاد و زمان‌بندی جلسات آموزشی.
- **سیستم حضور و غیاب هوشمند:** ثبت وضعیت حضور (حاضر، غایب، تأخیر) در هر جلسه و محاسبه خودکار درصد حضور دانشجویان.
- **چرخه حیات تکالیف (Assignments):** تعریف تکلیف، تعیین مهلت (Deadline)، ارسال پاسخ توسط دانشجو و فرآیند نمره‌دهی و بازخورد توسط استاد.
- **مدیریت جلسات کلاس:** ایجاد جلسات با عنوان، تاریخ و توضیحات + لینک مستقیم به حضور و غیاب هر جلسه.

### 📢 سیستم اطلاعیه‌ها (Announcements)

- انتشار اطلاعیه‌های عمومی یا هدفمند (Targeted).
- تعیین مخاطب بر اساس کلاس، نقش یا ترکیب هر دو.
- قابلیت رهگیری وضعیت مشاهده (Seen/Unseen) برای هر کاربر.
- بازنشانی وضعیت مشاهده پس از ویرایش اطلاعیه.

### 📊 داشبوردهای تحلیلی و آماری (Analytics Dashboards)

- **داشبورد مدیر:** نظارت بر آمار کلان سامانه، توزیع نقش‌ها (نمودار دایره‌ای) و آخرین کلاس‌های ثبت‌شده.
- **داشبورد استاد:** رصد تکالیف نیازمند تصحیح (نمودار میله‌ای)، وضعیت حضور کلاس‌ها و جلسات اخیر.
- **داشبورد دانشجو:** نمایش درصد حضور (نمودار دایره‌ای)، تکالیف در انتظار ارسال و اطلاعیه‌های خوانده‌نشده.
- **مصورسازی داده‌ها:** استفاده از کتابخانه `Recharts` برای نمایش نمودارهای دایره‌ای و میله‌ای.

### 🎨 تجربه کاربری و رابط کاربری (UX/UI)

- **طراحی کاملاً ریسپانسیو:** پشتیبانی از موبایل، تبلت و دسکتاپ.
- **کارت‌های موبایل:** نمایش داده‌ها به‌صورت کارت در صفحات کوچک به‌جای جدول.
- **سیستم نوتیفیکیشن (Toast):** بازخورد لحظه‌ای به کاربر پس از هر عملیات.
- **مدال‌های بهینه:** بستن با کلید Escape، کلیک خارج از مدال و مدیریت اسکرول صفحه.
- **خطای مرزی (Error Boundary):** مدیریت خطاهای غیرمنتظره در رندر.
- **فونت فارسی وزیرمتن:** پشتیبانی کامل از زبان فارسی و جهت‌گیری RTL.

## 📂 معماری و ساختار دایرکتوری‌ها

معماری پروژه به‌صورت ماژولار و مقیاس‌پذیر طراحی شده است تا توسعه و نگهداری آن در فازهای آتی تسهیل گردد:

</div>

```text
src/
├── components/
│   ├── common/          # کامپوننت‌های مشترک (Header, Sidebar, EmptyState, Loading, ErrorBoundary)
│   └── ui/              # کامپوننت‌های پایه (Button, Input, Select, Table, Modal, Card, StatCard, ...)
├── configs/             # تنظیمات سراسری و ثابت‌های محیطی
├── contexts/            # مدیریت Stateهای سراسری (Auth, Toast)
├── hooks/               # هوک‌های اختصاصی (useToast)
├── layouts/             # ساختارهای کلان صفحات (MainLayout)
├── pages/
│   ├── announcements/   # ماژول اطلاعیه‌ها + فرم + اعتبارسنجی
│   ├── assignments/     # ماژول تکالیف + فرم + اعتبارسنجی + پاسخ‌ها
│   ├── attendance/      # ماژول حضور و غیاب (نمای استاد + نمای دانشجو)
│   ├── auth/            # صفحه ورود (نسخه قدیمی)
│   ├── classes/         # ماژول کلاس‌ها + جزئیات + جلسات + اعتبارسنجی
│   ├── dashboard/       # داشبورد نقش‌محور (Admin, Teacher, Student)
│   ├── errors/          # صفحات خطا (404, 403)
│   ├── profile/         # پروفایل کاربری
│   └── users/           # ماژول مدیریت کاربران + فیلترها + اعتبارسنجی
├── routes/              # پیکربندی Router و محافظ‌های دسترسی (Guards)
├── services/
│   ├── api/             # لایه انتزاعی ارتباط با API (axiosInstance, baseApi)
│   └── modules/         # سرویس‌های تخصصی هر ماژول
├── types/               # تعریف Interfaceها و Typeهای TypeScript
└── utils/               # توابع کمکی (Utility Functions)
```

## 🚀 راهنمای نصب و راه‌اندازی (Setup & Installation)

برای راه‌اندازی محیط توسعه (Development Environment)، مراحل زیر را به ترتیب اجرا نمایید:

</div>

<div dir="rtl">

### ۱. دریافت و نصب وابستگی‌ها:

</div>

```bash
git clone <repository-url>
cd educonnect
npm install
```

<div dir="rtl">

### ۲. پیکربندی متغیرهای محیطی:

فایل `.env.example` را کپی کرده و با نام `.env` در ریشه پروژه ذخیره نمایید:

</div>

```bash
cp .env.example .env
```

```env
# .env
VITE_API_BASE_URL=http://localhost:3001
VITE_APP_ENV=development
VITE_STORAGE_PREFIX=educonnect_dev_
```

<div dir="rtl">

### ۳. اجرای سرور شبیه‌ساز (Mock API):

</div>

```bash
npm run server
```

<div dir="rtl">

> این دستور `json-server` را برای ارائه API فیک بر اساس فایل `db.json` در پورت `3001` اجرا می‌کند.

</div>

<div dir="rtl">

### ۴. اجرای سرور توسعه فرانت‌اند:

</div>

```bash
npm run dev
```

<div dir="rtl">

> پروژه به‌صورت پیش‌فرض در آدرس `http://localhost:5173` در دسترس خواهد بود.

</div>

<div dir="rtl">

### ۵. ساخت نسخه نهایی (Production Build):

</div>

```bash
npm run build
```

## 🗺 نقشه راه توسعه (Development Roadmap)

فرآیند توسعه این سامانه در دو بخش **فازهای هسته (Core)** و **فازهای توسعه‌ای (Advanced)** برنامه‌ریزی شده است:

### 🔹 فازهای هسته (اجرای قطعی) ✅

1. **زیرساخت و اسکلت پروژه:** راه‌اندازی Vite، Tailwind، Router و لایه API.
2. **احراز هویت و کنترل دسترسی:** پیاده‌سازی Context، Protected Routes و Role Guards.
3. **مدیریت کاربران:** CRUD کامل کاربران با تفکیک نقش‌ها و اعتبارسنجی فرم‌ها.
4. **مدیریت کلاس‌ها و جلسات:** ایجاد دوره‌ها، تخصیص استاد/دانشجو و زمان‌بندی جلسات.
5. **حضور و غیاب:** ثبت و محاسبه آماری حضور در جلسات.
6. **اطلاعیه‌ها:** سیستم انتشار و مشاهده پیام‌های آموزشی.
7. **تکالیف و ارزیابی:** چرخه کامل تعریف، ارسال و تصحیح تکالیف.
8. **داشبوردهای اختصاصی:** نمایش آمار و نمودارهای تحلیلی برای هر نقش.
9. **یکپارچه‌سازی و UX:** بهینه‌سازی فرم‌ها، Error Handling، Loading States و Empty States.
10. **تست و پایداری:** رفع باگ‌ها، سناریوهای دمو و آماده‌سازی برای ارائه نهایی.

### 🔸 فازهای توسعه‌ای (امکانات تکمیلی) 🚧

- **مرکز اعلان‌ها (Notification Center):** مدیریت اعلان‌های سیستمی و Deadlineها.
- **سیستم وضعیت‌ها (Lifecycle Management):** پشتیبانی از حالت‌های Draft، Published و Archived.
- **پروفایل پیشرفته و لاگ فعالیت‌ها:** ثبت تاریخچه عملیات مدیریتی و کاربری (Activity Log).
- **اتاق گفتگوی آموزشی (Discussion Room):** پیاده‌سازی چت کلاسی و پیام‌رسانی.
- **تقویم آموزشی و یادآورها (Calendar & Reminders):** نمایش بصری رویدادها و مهلت‌ها.
- **سیستم آزمون‌ساز آنلاین (Exams):** پشتیبانی از سوالات تستی، تشریحی و تصحیح خودکار.
